## 📑 Sectores Comerciales y Proyectos Desarrollados

### 🦷 1. Sector Salud & Clínicas Odontológicas
Diseños enfocados en agendamiento de citas, presentación de especialistas, testimonios y servicios de ortodoncia, implantología y estética dental:
- `sociedad_odontologica_huila`: Plataforma odontológica institucional (Neiva, Huila).
- `sonrisas_sanas_medellin`: Portal de servicios odontológicos integrales (Medellín).
- `grupo_odontologico_goi_bogota`: Clínica odontológica avanzada (Bogotá).
- `dr_manuel_maya_dental_barranquilla`: Consultorio odontológico especializado (Barranquilla).
- `odontologia_ciudad_jardin_cali` / `prisma_odontologia_estetica_cali`: Odontología estética y de alta tecnología (Cali).
- `saludent_colombia_armenia` / `happy_clinica_dental_armenia`: Clínicas dentales regionales (Armenia).
- `sana_estudio_dental_pereira` / `savanna_clinica_odontologica_rionegro`: Odontología especializada (Pereira / Rionegro).

### 🐾 2. Sector Veterinario & Pet Shops
Sistemas web para clínicas de animales, servicios de urgencias 24/7, vacunación, pet shops y laboratorios clínicos:
- `gb_hospital_veterinario_bogota` / `veterinaria_perros_gatos_castilla_bogota`: Hospitales y clínicas veterinarias (Bogotá).
- `felican_centro_veterinario_medellin`: Centro veterinario y atención especializada (Medellín).
- `hospital_veterinario_ar_palmira` / `todocan_veterinaria_palmira`: Centros de atención animal (Palmira).
- `tu_veterinario_pereira_dosquebradas` / `veterinaria_felican_pereira`: Red veterinaria (Eje Cafetero).
- `zoomedica_veterinaria_tunja` / `mundo_mascota_villavicencio` / `vasam_petshop_valledupar`: Clínicas y tiendas de mascotas regionales.

### 🥩 3. Sector Gastronómico, Parrillas & Restaurantes
Menús digitales interactivos, catálogos de cortes de carne, reservas y pedidos en línea:
- `restaurante_avenida_neiva` / `serendipia_neiva`: Experiencias gastronómicas locales (Neiva, Huila).
- `rio_restaurante_bogota` / `gipsy_grill_park_cajica`: Restaurantes campestres y gastrobares (Bogotá / Sabana).
- `la_estacion_gastrobar_cali` / `la_cataleya_restaurante_palmira`: Gastrobares y cocina de autor (Valle del Cauca).
- `pepe_anca_cartagena` / `restaurante_santa_mesa_santamarta` / `restaurante_el_trapiche_barranquilla`: Restaurantes de la Costa Caribe.
- `tango_pasion_por_la_carne` / `hernando_parrilla_bucaramanga` / `parrilla_el_limonar_armenia`: Especialistas en carnes y parrillas.

### 🔨 4. Sector Industrial, Ferretero & Comercio Técnico
Catálogos de herramientas, materiales de construcción y suministros industriales:
- `ferreteria_universal_neiva`: Ferretería principal y suministros para la construcción (Neiva).
- `la_ferreteria_paloquemao_bogota`: Comercio de herramientas y tornillería (Bogotá).
- `ferreteria_tecnica_medellin` / `ferreteria_el_ingenio_cali`: Ferreterías industriales y técnicas.
- `master_tools_ferreteria`: Catálogo digital de maquinaria y herramienta pesada.

## 🛠️ Tecnologías y Arquitectura

- **Frontend:** HTML5 semántico, CSS3 modular (Flexbox & Grid), JavaScript moderno (ES6+).
- **Diseño Responsivo:** Compatibilidad multi-dispositivo (Smartphones, Tablets, Laptops y Pantallas Ultra-wide).
- **SEO & Rendimiento:** Optimización de tiempos de carga, compresión de activos y meta-etiquetas Open Graph para redes sociales.

## 🚀 Cómo Visualizar los Proyectos Localmente

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Sais-gallego/trabajo_so.git
   cd trabajo_so
   ```

2. **Abrir cualquier proyecto en tu navegador:**
   - Puedes ingresar a cualquiera de las carpetas y abrir su archivo `index.html` directamente en tu navegador o mediante un servidor estático:
   ```bash
   # Utilizando Python
   python -m http.server 8000
   ```
   - Abre `http://localhost:8000` en tu navegador para explorar todos los comercios.
